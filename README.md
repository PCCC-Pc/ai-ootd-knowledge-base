# AI OOTD Knowledge Base

以可靠來源建立個人化穿搭知識庫，並將知識整理成適合穿搭初學者的 HTML 教學簡報。

## 專案目標
- 建立八大穿搭知識主題的 LLM Wiki。
- 蒐集並整理 8–10 篇具可信度的來源。
- 為每篇來源建立可追溯的證據卡。
- 以實際穿搭情境與案例製作 HTML 教學簡報。
- 規劃 AI OOTD 未來功能，核心方向為結合天氣、季節、場合、活動與每日行程推薦 Outfit。

## 知識主題
1. 個人色彩分析
2. 身形分析
3. 穿搭風格
4. 色彩搭配
5. 服裝搭配
6. 場合穿搭
7. 衣櫃管理
8. AI 穿搭推薦

## 目錄
- `AGENTS.md`：AI 專案總規則。
- `raw/`：原始來源資料與書目資訊。
- `cards/`：來源證據卡。
- `wiki/`：整理後的知識庫。
- `workflow/`：Graph、Loop 與檢查流程。
- `slides/`：HTML 教學簡報。
- `reports/`：執行紀錄、審查結果與反思。
- `assets/`：簡報使用的圖片及其他素材。
- `.agents/workflows/`：可重複執行的工作流程規格。

## 語言與引用
內容使用繁體中文（台灣用語），專業術語保留 English。引用採 APA 第七版，提供 DOI 或原始網址。重要主張必須能追溯至來源；不得捏造文獻或研究結論。

## 目前狀態
目前為專案初始化階段。此 Repository 尚未完成來源蒐集、Wiki 內容整理、HTML 簡報及 Calendar Memory 串接。未來功能會在實際完成及測試後才更新狀態。
