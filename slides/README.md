# HTML Teaching Slides

12 頁 HTML 教學簡報，採用 **Korean/Japanese Lookbook × Fashion Editorial** 視覺方向。

## 直接開啟
https://pccc-pc.github.io/ai-ootd-knowledge-base/slides/index.html

## 教學定位
- 讀者：一般穿搭初學者。
- 呈現方式：實例應用型，以穿搭情境、案例及搭配理由為主。
- 語言：繁體中文（台灣用語）。
- 內容原則：知識性主張可追溯至 Wiki 與來源證據卡。
- 研究發現、教學示例、專案概念與未來功能分開標示。

## 操作方式
- 側邊頁碼標籤：直接跳到指定頁。
- 上一頁／下一頁按鈕。
- 滑鼠滾輪、鍵盤方向鍵、PageUp／PageDown。
- 手機可左右滑動。
- 進度條顯示目前頁數。

## 視覺素材
穿搭照片來自 Pexels，作為造型與版型的 Lookbook 視覺示例，不作為研究證據。每頁頁尾附近列有 Photo Credits。

## 來源與內容
逐頁內容草稿：`draft.md`；教學順序：`outline.md`；內容忠實度檢查：`../reports/slide-draft-fidelity-review.md`。

## 驗證
GitHub Actions 會檢查頁數、Wiki 主題數、來源卡對應、HTML／JavaScript 語法及本地檔案存在性。瀏覽器操作及不同裝置的實際畫面仍需人工驗收。
