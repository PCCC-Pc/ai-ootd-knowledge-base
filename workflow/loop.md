# Local Loop Rules

## 證據卡 Loop
1. 依原始來源產生證據卡草稿。
2. 檢查 APA 7th、DOI／URL、研究目的、方法、結果、限制及可支持主張。
3. 只修正被指出的欄位。
4. 最多 2 輪；來源不足或原始資料不可得時停止並註記。

## HTML 渲染 Loop
1. 由已通過審查的簡報稿產生 HTML。
2. 在瀏覽器開啟並檢查導覽、連結、文字溢出、圖片與響應式版面。
3. 修正對應投影片或樣式，不任意修改已審查的知識內容。
4. 再次渲染及檢查，保留檢查紀錄。

## 停止條件
每個局部 Loop 最多 2 輪。若仍失敗，將問題交回 Graph 指定節點並記錄，不無限重跑。
