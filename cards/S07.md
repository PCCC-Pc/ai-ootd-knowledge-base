## Scope and key points
The survey reviews AI-driven fashion recommender systems, particularly image-based approaches. It explains that fashion recommendation differs from generic recommendation because outfit compatibility is central, not merely item similarity. It discusses user, clothing and contextual attributes and distinguishes item retrieval, complementary-item recommendation, whole-outfit recommendation and capsule-wardrobe recommendation.

## Wiki claims this card can support
1. Fashion recommendation needs to model compatibility among clothing items, not only similarity.
2. User attributes, garment attributes and context can all be represented as recommendation inputs.
3. Whole-outfit and capsule-wardrobe recommendation are distinct task types in the literature.

## Limitations / boundaries
- This is a survey, not a user trial of our proposed application.
- A review of prior context-aware or wardrobe systems is not evidence that calendar integration or daily notifications have been implemented or proven effective.
- Fashion remains subjective; model results and taxonomies should not be presented as universal styling rules.
